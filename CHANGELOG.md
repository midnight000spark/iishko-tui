# Changelog

Все заметные изменения проекта. Версии — по SemVer.

## [0.1.0] — 2026-11-22

Первая публичная версия.

### Возможности

- Локальный TUI-плагин для стабильного OpenCode major 2 (>= 2.2.5): каталог
  ИИШКО, поиск, сведения о моделях, фильтры, смена ранга и аккаунта.
- Обновление списка моделей по публичным данным сайта: предпросмотр, режимы
  «Только добавить» и «Полная синхронизация», запись только после явного
  подтверждения именно этого плана.
- Переносимая сборка: один ESM-бандл; получателю не нужны Python, WSL,
  отдельный Bun/Node.js или установка зависимостей.

### Безопасность

- Изменяется только существующий блок `models` выбранного локального
  провайдера; комментарии, BOM, переводы строк и байты вне цели сохраняются.
- Уникальный бэкап рядом с конфигом, межпроцессная блокировка, повторная
  проверка хеша исходника, запись через временный файл и атомарная замена.
- На Windows проверяются владелец и ACL исходника, а владелец и DACL
  бэкапа/временного файла защищаются до записи содержимого.
- Плагин не читает файлы с секретами и не выполняет платных проб API
  провайдера.
- Удаление в полном режиме — только при одновременных `down`, uptime <= 10%
  и не менее 12 провальных полос; отсутствующие на сайте модели сохраняются.

### Ограничения

- Интерактивная проверка в живом Windows/OpenCode ещё не выполнена;
  Windows-путь проверен только в CI-фикстурах. Windows UX не менялся.
- Стабильный статус или сертификация проекта не заявляются.
