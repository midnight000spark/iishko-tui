# iishko-tui

Один локальный TUI-плагин для **стабильного OpenCode major 2, версия >= 2.2.5**: каталог ИИШКО и
обновление списка моделей по публичным данным сайта. OpenCode и провайдер
ИИШКО должны быть уже настроены. **Python, WSL, отдельный Bun/Node.js и
установка зависимостей получателю не нужны.** Это не установщик OpenCode.

Публичный репозиторий: <https://github.com/midnight000spark/iishko-tui>.
Готовые сборки: <https://github.com/midnight000spark/iishko-tui/releases>.

## Windows: установка из ZIP

1. Получите ZIP `iishko-tui-<версия>-windows.zip` от доверенного отправителя.
   Плагин исполняет локальный код с вашими правами — не устанавливайте
   неизвестную сборку. Если отправитель передал SHA-256 отдельным доверенным
   каналом, сравните его с `Get-FileHash <путь-к-ZIP> -Algorithm SHA256`.
2. Правой кнопкой по ZIP → **Извлечь всё**. Не запускайте установщик внутри ZIP.
3. Закройте OpenCode на время замены файлов плагина. В извлечённой папке дважды
   нажмите **install.cmd**. Не используйте «Запуск от имени администратора».
4. Прочитайте назначение установки и введите **YES**. Если плагин уже установлен,
   подтвердите замену отдельно. Предыдущая проверенная сборка сохраняется.
5. Откройте OpenCode. При необходимости выполните `/reload`. В **Ctrl+P** найдите
   «ИИШКО» / каталог. Меню `/iishko-tui`, каталог `/iishko-catalog`, обновление
   `/iishko-update` — команды плагина, а не запросы к модели.

В ZIP лежат `install.cmd`, `install.ps1`, этот README, `windows-smoke.md` и
папка `iishko-tui` с готовым JavaScript, минимальным `package.json`, контрольными
суммами и лицензиями сторонних зависимостей. Не добавляйте туда другие файлы:
установщик откажется копировать неизвестное содержимое.

**Путь установки:** `%XDG_CONFIG_HOME%\opencode\plugins\iishko-tui`, если переменная
задана; иначе `%USERPROFILE%\.config\opencode\plugins\iishko-tui`.
Симлинки, junction и сетевые пути не поддерживаются. `cli.json` и настройки
провайдера установщик не меняет: OpenCode обнаруживает папку автоматически.

### PowerShell и ограничения организации

`install.cmd` вызывает штатный Windows PowerShell 5.1 с `-NoProfile` и
`-ExecutionPolicy Bypass` **только для своего процесса**. Настройки политики
пользователя/машины не изменяются; администраторские права не нужны. Установка
всё равно требует вашего явного YES. Это не способ обойти MachinePolicy или
UserPolicy организации: если запуск запрещён управляемой политикой, обратитесь
к администратору. Не отключайте системную защиту ради плагина.

Если `opencode` найден в PATH, установщик проверяет только `--version`, без
запуска TUI/сервиса. Старый, неизвестный, preview или иной major не принимается.
Если команды нет в PATH, выводится предупреждение: файлы можно скопировать,
но стабильный OpenCode major 2, версия >= 2.2.5, по-прежнему обязателен.
Будущий major 3 не считается совместимым автоматически; проверка версии есть
и при работе плагина. Установщик ничего не скачивает и сам не запускает OpenCode.

Отдельно от установщика, при **записи конфига на Windows** плагин вызывает узкий
встроенный помощник ACL через штатный Windows PowerShell 5.1 по системному пути.
Он получает фиксированный код через `-EncodedCommand`, а пути и дескрипторы
прав — как JSON-данные через stdin, не как исполняемый текст. Используются
`-NoProfile` и `-NonInteractive`, без shell, поиска программы в PATH,
`-ExecutionPolicy Bypass`, повышения прав или изменения системной политики.
Помощник нужен только для сохранения владельца и прав доступа файлов, а не
для запуска Python, команд обновления каталога или платных проб. Если PowerShell
или проверка ACL недоступны/запрещены, запись безопасно отменяется: не отключайте
защиту и не запускайте OpenCode от администратора ради обхода ошибки.

Контрольные суммы внутри папки обнаруживают повреждение, **не доказывают
подлинность**: злоумышленник может заменить и код, и manifest, и установщик.
Получайте весь ZIP из доверенного источника.

## Linux: ручная установка

Готовый архив релиза содержит папку `iishko-tui` с уже собранным JavaScript.
Устанавливается **только эта папка**; Python, Bun/Node.js и установка
зависимостей не нужны.

1. Закройте OpenCode или будьте готовы выполнить `/reload`.
2. Если плагин уже установлен, сохраните текущую папку
   `${XDG_CONFIG_HOME:-$HOME/.config}/opencode/plugins/iishko-tui` в резервное
   место **вне** `plugins`. Не удаляйте её рекурсивно и не очищайте каталог
   `opencode`.
3. Скопируйте папку `iishko-tui` из архива целиком в
   `${XDG_CONFIG_HOME:-$HOME/.config}/opencode/plugins/iishko-tui`, не смешивая
   файлы разных версий.
4. Запустите OpenCode; при необходимости выполните `/reload`. Проверьте
   `/iishko-tui`, `/iishko-catalog` и `/iishko-update`.

Нужен стабильный OpenCode major 2, версия >= 2.2.5. Плагин ничего не скачивает
при установке и не меняет настройки провайдера. Если SHA-256 передан отдельным
доверенным каналом, сравните его до установки.

## Как пользоваться

Откройте каталог, выберите свой локально настроенный аккаунт и ранг. Ранг сайта
не подтверждает реальный доступ или остаток кредита вашего ключа. Плагин не
читает файлы с секретами, не разрешает ссылки на ключи и не делает платных
проб API провайдера. Публичные данные сайта могут отличаться от вашего доступа.

В каталоге: ввод текста — поиск, **Enter** — сведения о модели, **Esc** — назад.
Действия внизу окна открывают фильтры (`Ctrl+F`), смену ранга (`Ctrl+G`),
обновление данных сайта (`Ctrl+O`) и смену аккаунта (`Ctrl+A`, если их несколько).
Обновление данных каталога само по себе **не записывает** список моделей в конфиг.

Для обновления выберите:

1. Откройте `/iishko-update`, выберите нужный аккаунт/провайдер и свой ранг.
   Подтверждение ранга требуется каждый раз.
2. Выберите **Только добавить** — рекомендуемый режим без удалений;
   **Полная синхронизация** нужна только если вы хотите также убрать доказанно неработающие модели.
3. Изучите предпросмотр: локальный путь, провайдер, добавления/удаления и причины.
4. Только явное подтверждение записывает **именно этот** план. Отмена не пишет.

Нельзя одновременно запускать несколько операций. Перезагрузка/отключение
плагина отменяет незавершённую работу. При конфликте, устаревшем плане,
изменённом конфиге, ошибке схемы/сети или неполных данных обновление запрещается:
загрузите свежие данные и создайте новый предпросмотр, не обходите проверку.

### Что обновляется и что остаётся

* Изменяется только существующий блок `models` выбранного локального провайдера.
  Существующие limit/cost/name и пользовательские метаданные сохраняются;
  недостающие данные могут дополняться публичными models.dev/ценами сайта.
  Неизвестные лимиты и цены не выдумываются.
* Добавляются подходящие рабочие модели с известным доступным рангом.
  Неизвестный ранг не означает «доступна всем».
* В полном режиме удаление по плохому состоянию требует одновременно `down`,
  uptime <= 10% и не менее 12 провальных полос. `busy`, `up`, неизвестные и
  неизмеренные модели сохраняются; исключения `always_keep` защищены политикой.
* **Отсутствующие на сайте модели сохраняются.** Публичный источник не гарантирует
  авторитетную полноту списка, поэтому TUI не предлагает удаление таких моделей.
  Полный режим допускает только удаления по строгому условию `down` выше;
  частичный/повреждённый ответ не повод для массового удаления.
  Режим «Только добавить» вообще не удаляет модели.
* Перед записью проверяется официальная схема (нужен HTTPS-доступ), создаётся
  уникальный бэкап рядом с конфигом. Есть межпроцессная блокировка и повторная
  проверка хеша исходника; запись — через временный файл и атомарную замену,
  без удаления оригинала ради принудительной замены. Комментарии/BOM/переводы
  строк и байты вне целевого значения сохраняются.
* На Windows исходный файл должен принадлежать текущему пользователю и иметь
  поддерживаемую проверяемую ACL. Владелец и DACL бэкапа/временного файла
  защищаются и проверяются **до записи содержимого**; более широкие права
  родительского каталога не должны расширять доступ к этим копиям. Изменение
  ACL исходника или невозможность подтвердить защиту отменяет замену.

### Важно: это локальная конфигурация

Плагин работает **на машине, где запущен TUI**, даже если TUI подключён к
удалённому серверу. Он не меняет конфиг удалённого сервера и не обещает изменить
все эффективные модели OpenCode. Глобальные JSON/JSONC ищутся в документированных
XDG/home-путях; явный локальный `configPath` — отдельная настройка плагина для
опытного пользователя (при его задании предлагается только этот файл). При неоднозначных документах/провайдерах, динамическом
endpoint или inline-конфигурации инструмент отказывается угадывать цель.
Проектные, встроенные, управляемые и унаследованные модели вне выбранного
документа не удаляются этим плагином. Сверяйте путь в предпросмотре.

Сеть нужна для публичного сайта ИИШКО, models.dev и официальной схемы OpenCode.
Закрытый доступ к ним — безопасный отказ, а не разрешение записать без проверки.
Никакого фонового сервиса или периодических платных запросов здесь нет.

## Миграция со старой Python-сборки

В новой переносимой сборке **удалены** `pull`, платный `probe`, локальный
консенсус, запуск Python CLI, отдельный файл плана и панель вывода subprocess.
Загрузка сайта, планирование и обновление моделей теперь выполняются внутри
плагина; единственное узкое исключение для runtime-подпроцесса — описанный выше
Windows PowerShell ACL-помощник. Соседний самостоятельный Python-проект не
изменяется и больше не является зависимостью. Платных запросов этот помощник
не выполняет.

Перед установкой уберите старую ссылку/ручную регистрацию этой же сборки,
чтобы не загружать плагин дважды. Установщик намеренно не удаляет симлинки и
не редактирует ваши записи в `cli.json`/`opencode.json(c)`. Старый каталог без
корректного release-manifest или с посторонними файлами не заменяется: сохраните
его вручную **вне `plugins`**, затем повторите установку. Не оставляйте копию
старого плагина под другим именем внутри `plugins` — она тоже обнаруживается.

## Восстановление и удаление

**После обновления моделей:** сохраните сообщение с путём бэкапа. Если нужно
вернуть конфиг, прекратите новые обновления, сохраните текущий файл отдельно
и восстановите нужный бэкап вручную в исходный путь. Это откат всего документа:
не затрите более поздние изменения других настроек. После сохранения OpenCode
перечитывает конфиг; при необходимости `/reload`. Не отправляйте конфиг/бэкап
в чат или issue: там могут быть секреты. Не удаляйте чужую блокировку наугад.

**После установки плагина:** прежняя сборка лежит в
`<global-config>/iishko-plugin-backups/<случайный-id>`, путь показан установщиком.
При ошибке замены он пытается вернуть её автоматически. При ручном откате
закройте OpenCode, перенесите текущую папку `plugins/iishko-tui` в безопасное
место вне `plugins`, затем перенесите нужную резервную папку обратно под именем
`plugins/iishko-tui`. Не объединяйте файлы разных версий. Если файлы заблокированы
Windows, закройте приложение и повторите — не удаляйте конфиг.

**Удалить плагин:** закройте OpenCode и переместите только
`plugins/iishko-tui` за пределы `plugins`. Не удаляйте весь каталог `opencode`,
ваши конфиги или бэкапы. При ручной регистрации отдельно уберите только свою
запись о плагине, сохранив остальные настройки.

## Разработка и выпуск

Только разработчику нужен Bun **1.4.4**:

```sh
bun install --frozen-lockfile
bun audit --audit-level=high
bun run typecheck
bun test
bun run build
bun run verify:release
bun run smoke:bundle
```

`build` создаёт только `.tmp/release/`, не устанавливает плагин в живой OpenCode.
JSONC/Ajv и их транзитивные зависимости включены в один ESM `tui.js`;
`@opencode/plugin/tui`, Solid и OpenTUI разрешаются хостом, а не дублируются.
Нет node_modules/devDependencies в артефакте, sourcemap или встраивания env.
Полные тексты лицензий включённых библиотек — `THIRD-PARTY-NOTICES.txt`.
Проект распространяется по лицензии MIT; полный текст — в `LICENSE` исходного
репозитория и в начале `iishko-tui/THIRD-PARTY-NOTICES.txt` готового ZIP.

Техническая сводка проверок и закрытия замечаний аудита:
`docs/portable-verification.md` в исходном проекте. Она отдельно отмечает
выполненные Linux-проверки и ещё не выполненные Windows/интерактивные проверки.

CI проверяет Linux/Windows, frozen lock, уязвимости, типы, тесты, содержимое
release и установку PowerShell 5.1 **только во временные фикстуры**. Windows job
делает ZIP штатным `Compress-Archive` и проверяет его после распаковки. Результат —
artifact `iishko-tui-windows` (внутри настоящий ZIP и внешний SHA-256), без публикации.
На Linux готовую папку можно упаковать установленным ZIP-инструментом; сам build
не требует дополнительного архиватора и не пишет собственный ZIP-код.

Проверка в живом Windows/OpenCode — отдельный этап: [чеклист](docs/windows-smoke.md)
(в ZIP файл `windows-smoke.md`). Наличие workflow не означает успешный запуск CI
или проверку интерактивного TUI. До фактического прогона не заявляйте обратное.

Контракты хоста: [плагины](https://opencode.ai/docs/build/plugins),
[TUI](https://opencode.ai/docs/build/plugins/cli),
[автообнаружение](https://opencode.ai/docs/cli/plugins).
