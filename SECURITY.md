# Безопасность

Плагин исполняет локальный код с правами пользователя OpenCode и может
изменять только выбранный блок `models` локального конфига после явного
подтверждения. Об ошибках безопасности сообщайте приватно.

## Как сообщить об уязвимости

Не создавайте публичный issue с деталями проблемы.

1. Если в репозитории включена приватная форма GitHub Security Advisories,
   используйте её:
   <https://github.com/midnight000spark/iishko-tui/security/advisories/new>
2. Если приватная форма недоступна, свяжитесь с мейнтейнером по уже известному
   вам приватному каналу.

Приватный приём отчётов может быть ещё не настроен и не гарантируется.
Если безопасный приватный канал недоступен, сообщите только о факте проблемы
без деталей и дождитесь ответа. Не публикуйте эксплойт, секреты или приватные
данные в открытом виде.

## Что нельзя публиковать

Никогда не прикладывайте к issue, pull request, чатам, скриншотам или логам:

- API-ключи, токены, пароли и содержимое `.env`;
- конфиги OpenCode (`opencode.json`, `opencode.jsonc`, `cli.json`) и настройки
  провайдера;
- бэкапы конфигов и установленного плагина (`iishko-plugin-backups`, файлы
  рядом с конфигом);
- приватные пути, имена пользователей и другие персональные данные.

При необходимости воспроизведения замените значения заполнителями и заранее
проверьте вложение. Если секрет уже опубликован, считайте его скомпрометированным:
отзовите ключ и сообщите об этом приватно.

## Область действия

Полезны сообщения о: обходе подтверждения записи, изменении файлов вне
выбранного блока `models`, обходе проверок схемы/блокировки/ACL, утечке
содержимого конфигов или секретов, подмене данных обновления, небезопасной
обработке путей и архива.

## Поддерживаемые версии

Поддерживается последняя опубликованная версия `0.1.x`. Стабильность или
сертификация проекта не заявляются.
